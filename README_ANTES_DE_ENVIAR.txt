MONSTER HIGH — LAUANA | PUBLICAÇÃO FÁCIL NO GITHUB PAGES

Esta é uma versão compacta para publicar pelo navegador do GitHub.
As imagens, estilos e scripts estão incorporados aos HTMLs para não enviar centenas de arquivos.

CONTEÚDO
- index.html: Edição Maré Suprema (menu, arena e atos recentes).
- campanha/index.html: campanha clássica dos 8 portais e 49 missões.

COMO ENVIAR PELO SITE DO GITHUB
1. Extraia este ZIP.
2. Abra seu repositório no GitHub e use Add file > Upload files.
3. Arraste os arquivos e a pasta campanha para a página. São apenas dois HTMLs + README.
4. Confirme a mensagem do commit e clique em Commit changes.
5. Settings > Pages > Deploy from a branch > main > / (root) > Save.
6. Abra o endereço exibido pelo GitHub Pages.

AVISO
Esta edição compacta é voltada à publicação WEB. Instalação PWA/offline,
cache automático e futuros upgrades podem exigir o projeto completo.
Para continuar desenvolvendo a edição completa sem perder os recursos separados,
use o GitHub Desktop e o ZIP completo da Maré Suprema.
Não faça upload do ZIP diretamente: extraia seu conteúdo.
